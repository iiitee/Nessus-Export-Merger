# Nessus Export Merger
based on https://gist.github.com/btoews/2720173

combine .nessus export files  
**Note that scans must be of the same type (same plugins must be used), but they can be from different subnets or different parts of the same subnet.**

to run, place nessus_merge.py in the same directory as .nessus files to combine  
python nessus_merge.py
